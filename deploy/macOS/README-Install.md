# Desktop deployment retired

Inbox Utilities is moving to three Azure App Services with Microsoft Entra authentication, Managed Identity, Microsoft Graph, and SharePoint storage. Staff should not install or run these utilities from a desktop package.

The scripts and ZIP packages in this repository are legacy artifacts and do not represent the hosted architecture. Do not use them for production deployment or configure them to access a mapped drive.

See the [Inbox Utilities architecture and deployment guide](../../README.md) for Azure setup, Graph permissions, SharePoint configuration, and remaining deployment prerequisites.
